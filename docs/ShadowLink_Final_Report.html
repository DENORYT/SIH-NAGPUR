1. Executive Summary

ShadowLink is a comprehensive forensic intelligence platform designed for Law Enforcement Agencies (LEAs) to de-anonymize threat actors operating on the dark web. The core challenge in dark web investigations is the fragmentation of identity—criminals use multiple aliases, rapidly switch forums, and rotate infrastructure to evade capture.

ShadowLink solves this by fusing three distinct streams of intelligence to build a unified identity graph:

  1. Infrastructure Analysis: Correlating dark web (.onion) services to public internet (clearnet) infrastructure via cryptographic certificates and server misconfigurations.
  2. Cryptographic Correlation: Mapping reused PGP keys and cryptocurrency wallets across disparate personas.
  3. AI Stylometry: Using Natural Language Processing (NLP) to detect matching linguistic patterns across forums, identifying rebranded personas even when all other identifiers have been wiped.
Hackathon Compliance Note: To ensure strict adherence to ethical guidelines and privacy laws, 100% of the data processed in this demo is generated via a custom synthetic data engine. No real PII or live dark web scraping is utilized in the hackathon build.

3. The Three Intelligence Engines

3.1 Infrastructure Matcher

Many dark web operators misconfigure their hosting setups. This module scans a database of `.onion` sites and matches them against public IP addresses. It searches for:

  • SSL_CERT_MATCH: Identical TLS/SSL certificate hashes exposed on both the Tor network and the clearnet.
  • SERVER_BANNER: Highly specific HTTP server headers (e.g., custom Nginx versions + OS fingerprints) that uniquely identify a host.

3.2 Cryptographic Identity Graph

Using NetworkX, this engine scans the database for hard identifiers. If Actor A and Actor B both post a message containing the same Bitcoin Address (SAME_WALLET) or PGP Public Key Fingerprint (SAME_PGP), the engine automatically draws a high-confidence edge between the two nodes in the database.

3.3 AI Stylometry (Linguistic Analysis)

Criminals frequently "rebrand" by abandoning old accounts and creating new ones. While they can change their username and wallet, they cannot easily change their grammatical habits. This module uses:

  • TF-IDF Vectorization: Converts forum posts into mathematical arrays based on word frequencies.
  • Cosine Similarity: Calculates the geometric angle between text vectors. Matches exceeding a threshold (0.52) are flagged as potential rebranded aliases.
  • Human-in-the-loop: Matches are flagged as ai_suggested = TRUE. They must be manually verified by an analyst via the frontend dashboard before being treated as factual evidence.

4. Database Schema Design

The relational database is built on 6 core tables to capture the complex web of threat actor identities:

Table Name Purpose
actors The root entity representing the suspected human operator. Tracks risk category and confidence scores.
aliases The specific usernames used across different platforms (e.g., 'ghost77' on Nighthawk Market).
identifiers Stores PGP fingerprints and Crypto Wallets linked to specific aliases.
posts The raw text content scraped from forums, used for Stylometry analysis.
infra_leaks Records of matched Tor to Clearnet vulnerabilities.
trust_links The central relationships table containing edges (SAME_PGP, STYLE_MATCH, VOUCHED_FOR).

5. Project Deliverables & File Manifest

The following systems were successfully coded and delivered during the hackathon:

  • backend/app/seed/generate_seed.py: The ethical synthetic data engine utilizing the Faker library to generate ground-truth test data.
  • backend/app/modules/: Contains the logic for the three core analytics engines (Infra, Identity, Stylometry).
  • backend/app/api/routes.py: The FastAPI controllers exposing data to the frontend, including the /export endpoint for court-ready dossiers.
  • backend/app/main.py: The application entry point ensuring database provisioning on cold boots.
  • frontend/index.html & app.js: The zero-build, client-side dashboard featuring real-time Cytoscape.js visualizations.

6. Conclusion

ShadowLink successfully demonstrates how fusing network engineering, cryptography, and artificial intelligence can pierce the veil of dark web anonymity. By providing analysts with an interactive, mathematically backed identity graph, ShadowLink reduces investigation times from months to minutes.
